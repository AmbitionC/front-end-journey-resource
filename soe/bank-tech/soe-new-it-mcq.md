信息新技术题的范围很宽，但考查方式大多是“给一个场景，判断该用哪一层、哪种协议、哪种服务模式或哪个指标”。本篇对照国家电网 2027 版计算机类考试大纲第 45–48 项（人工智能基础、物联网基础、云计算基础、大数据基础），并在云计算一节顺带覆盖第 37 项「并行计算与异构计算」的基础（Amdahl 定律、CPU/GPU 分工）。标题中的“常考点”只表示复习重点，不代表任何出题统计；文中 12 道练习均为单选。

## 人工智能：先分清学习方式，再看评估指标

机器学习按“训练时拿到什么反馈”区分最稳妥：

| 学习方式 | 训练数据与反馈 | 典型任务 |
| --- | --- | --- |
| 监督学习 | 每个样本带标签（正确答案） | 分类（是否故障）、回归（预测负荷数值） |
| 无监督学习 | 没有标签，只有特征 | 聚类（用户用电行为分群）、降维、异常检测 |
| 强化学习 | 智能体与环境交互，按动作获得奖励信号 | 调度策略、机器人控制、博弈 |

强化学习的反馈是奖励而非每一步的正确动作，且奖励可能延迟，见 [Sutton 与 Barto 教材](http://incompleteideas.net/book/the-book-2nd.html)第 1 章。

**过拟合**指模型把训练集的噪声和偶然规律也记住了：训练误差很低，验证/测试误差明显更高。常见对策是增加有效数据、降低模型复杂度、正则化、提前停止，以及用验证集或交叉验证选择超参数。反过来，训练误差和验证误差都高，则更像欠拟合。

分类评估从混淆矩阵出发。设正类为“故障”：

| | 预测为正 | 预测为负 |
| --- | --- | --- |
| 实际为正 | TP（真正例） | FN（漏报） |
| 实际为负 | FP（误报） | TN（真负例） |

- 准确率 Accuracy = (TP + TN) / 全部样本
- 精确率 Precision = TP / (TP + FP)：报出来的“故障”里有多少是真的
- 召回率 Recall = TP / (TP + FN)：真正的故障里抓到了多少
- F1 = 2PR / (P + R)：精确率与召回率的调和平均

正类很少时，准确率会被大量 TN 抬高，必须同时看精确率和召回率。定义可核对 [scikit-learn 模型评估文档](https://scikit-learn.org/stable/modules/model_evaluation.html)；阈值与不平衡数据的处理可延伸阅读站内的[不平衡二分类评估](../../knowledge/data/analysis/imbalanced-classification-evaluation.md)。

### 高频考点题 1：哪个任务属于强化学习

下列四个任务中，最适合归为强化学习的是哪项？

- A. 用已标注“正常/异常”的历史波形训练分类器
- B. 对没有标签的用户用电曲线做聚类分群
- C. 让调度程序在仿真电网中反复尝试储能充放电策略，按运行成本和越限情况获得奖励或惩罚
- D. 用历史气象和负荷数据拟合次日负荷数值

**答案：C。** 通过与环境交互、依据奖励信号改进策略，是强化学习的特征。

**解析：** A 有现成标签且输出类别，是监督学习中的分类；D 也有标签（真实负荷），输出连续值，是监督学习中的回归；B 没有标签，按相似性分组，是无监督学习。C 没有“正确充放电量”标签，只能依据动作带来的成本和越限后果调整策略。

### 高频考点题 2：识别过拟合

某缺陷识别模型训练集准确率 99.6%，验证集准确率只有 78%；增加网络层数后训练集达到 100%，验证集降到 74%。下列判断与处置最合理的是哪项？

- A. 模型欠拟合，应继续加深网络
- B. 模型过拟合，可考虑扩充有效样本、加入正则化或提前停止，并用验证集选择模型
- C. 验证集准确率低说明验证集标注一定错误，应删掉验证集
- D. 只要训练集准确率达到 100%，测试集表现必然最好

**答案：B。** 训练表现极好而验证表现差且随复杂度增加继续变差，是典型过拟合。

**解析：** 欠拟合的特征是训练误差本身就高，A 与题设相反，继续加深只会加剧过拟合。C 把泛化差直接归咎于数据错误，没有依据；D 混淆了训练误差与泛化误差，训练集 100% 往往恰好是记住噪声的信号。

### 高频考点题 3：准确率高不等于模型好

在 1000 条巡检记录中，模型对“缺陷”（正类）的判别结果为：TP = 40，FP = 10，FN = 20，TN = 930。该模型的 F1 值约为多少？

- A. 0.97
- B. 0.80
- C. 0.73
- D. 0.67

**答案：C。** 精确率 0.8、召回率约 0.667，F1 约 0.73。

**解析：** 精确率 P = 40 / (40 + 10) = 0.8；召回率 R = 40 / (40 + 20) ≈ 0.667；F1 = 2 × 0.8 × 0.667 / (0.8 + 0.667) ≈ 0.727。A 是准确率 (40 + 930) / 1000 = 0.97，被 930 个真负例抬高，掩盖了三分之一缺陷被漏掉；B 是精确率；D 是召回率。

## 大语言模型与智能体：token、窗口、幻觉与闭环

当前主流大语言模型以 Transformer 为基础。[Transformer 原始论文](https://arxiv.org/abs/1706.03762)用自注意力让序列中每个位置直接读取其他位置的信息，便于并行训练；生成式模型再逐个 token 预测后续内容。几个基础概念：

- **token**：模型处理文本的基本单位，由分词器切分得到。一个 token 可能是一个词、半个词、一个汉字或几个字符，不能简单按“字数 = token 数”换算。
- **上下文窗口**：一次推理中模型能处理的 token 总上限。题设若说明“窗口包含输入与输出”，那么系统提示、历史对话、检索资料、用户问题和生成的回答都要计入。
- **幻觉**：模型生成流畅但与事实或给定资料不符的内容。检索增强（RAG）、要求引用来源、工具校验都能降低风险，但不能保证彻底消除。

站内的 [Transformer 架构](../../knowledge/llm/basics/transformer-arch.md)、[Token 与上下文窗口](../../knowledge/llm/basics/llm-token-context.md)和[大模型能力边界](../../knowledge/llm/basics/llm-capability-boundaries.md)有更完整的展开。

**多模态识别**是让模型处理文本之外的图像、语音、视频等模态：各模态先经编码器转换为向量表示，再在共享空间中对齐或融合，例如“看图回答问题”“语音转文字后检索”。延伸阅读见[多模态模型基础](../../knowledge/llm/basics/llm-multimodal-basics.md)。

**智能体（Agent）**不是“能聊天的模型”，而是围绕目标反复执行“感知 → 规划/决策 → 调用工具行动 → 观察结果 → 更新记忆”的闭环系统，通常由大模型（推理决策核心）、规划、记忆、工具四部分组成，并有明确的停止条件和权限边界。详见站内的[智能体架构](../../knowledge/llm/agent/agent-architecture.md)。

### 高频考点题 4：上下文窗口还剩多少

某模型上下文窗口为 8192 token，题设规定输入与输出共用该窗口。一次请求中：系统提示 1200 token，历史对话 4500 token，检索到的规程片段 1000 token，用户新问题 800 token。关于本次回答的最大生成长度及相关判断，下列说法正确的是哪项？

- A. 最多生成 692 token；即使附上了规程原文，回答仍可能出现与原文不符的内容，需要校验
- B. 最多生成 1692 token；检索资料不占用上下文窗口
- C. 最多生成 8192 token；窗口只限制输入
- D. 无法计算，因为 token 数必须等于汉字数才能相加

**答案：A。** 输入合计 7500 token，剩余 692 token；检索增强降低但不消除幻觉。

**解析：** 输入 = 1200 + 4500 + 1000 + 800 = 7500，剩余 8192 − 7500 = 692。B 漏算了检索片段，检索内容必须放进提示才能被模型读到，自然占用窗口。C 与“输入输出共用窗口”的题设矛盾。D 的错误在于题目已直接给出各部分的 token 数，它们可以直接相加。

### 高频考点题 5：智能体比普通问答多了什么

某单位想做“变电站巡检助手”：上传一张设备照片和一段语音描述后，系统能识别设备类型、查询台账、比对历史缺陷记录，必要时生成检修工单草稿并等待人工确认。下列关于该系统的说法，最准确的是哪项？

- A. 只要换用参数量更大的语言模型，无需工具和记忆就能查询本单位台账
- B. 照片和语音属于不同模态，必须分别训练两个互不相关的模型，无法在一个系统中联合使用
- C. 这是一个多模态输入的智能体：模型负责理解与决策，通过工具查询台账、写入工单草稿，用记忆保存历史上下文，并在关键动作前设置人工确认
- D. 智能体能自主行动，所以生成工单后应直接下发执行，不需要权限限制

**答案：C。** 多模态感知、工具调用、记忆与人工确认共同构成该智能体闭环。

**解析：** 模型参数再多，也不包含本单位实时台账，必须通过工具（数据库/接口查询）获取，A 错。多模态模型可以把图像、语音编码后在共享表示中对齐融合，B 错。D 忽略了权限边界，涉及生产操作的动作应设人工确认。

## 物联网：分层、协议和接入方式各管一件事

[ITU-T Y.2060](https://www.itu.int/rec/T-REC-Y.2060-201206-I) 将物联网参考模型分为设备层、网络层、服务支撑与应用支撑层、应用层。国内教材常简化为三层：

| 层次 | 职责 | 例子 |
| --- | --- | --- |
| 感知层 | 采集物理量、识别对象、执行控制 | 温湿度/电流传感器、RFID、摄像头、智能电表 |
| 网络层 | 把数据可靠地传上去、把指令传下来 | NB-IoT、4G/5G、光纤、电力线载波、LoRa 网关 |
| 应用层 | 数据处理并面向业务提供服务 | 用电信息采集、设备状态监测、配网自动化 |

在网络层与应用层之间再拆出**平台层**（设备接入管理、数据汇聚、物模型、通用分析能力），就是四层划分；电力物联网资料中常见“感知层、网络层、平台层、应用层”的四层表述。典型电力应用有输变电设备在线监测、用电信息采集、分布式光伏和充电桩接入。

**传感技术**把物理量转换为电信号，关注量程、精度、灵敏度和功耗；**传感网络**由大量低功耗节点自组织组网，经汇聚节点上送数据。

常见协议按用途分：

- **MQTT**：基于 TCP 的发布/订阅协议。客户端向代理（Broker）的某个主题（Topic）发布消息，订阅该主题的客户端由代理转发收到；发布者与订阅者彼此不需要知道对方地址。QoS 0 最多一次、QoS 1 至少一次（可能重复）、QoS 2 恰好一次。见 [OASIS MQTT 5.0 规范](https://docs.oasis-open.org/mqtt/mqtt/v5.0/mqtt-v5.0.html)。
- **CoAP**：面向受限设备的 REST 风格协议，运行在 UDP 上，用 GET/POST/PUT/DELETE 访问资源，用可确认（CON）消息实现简单的重传可靠性。见 [RFC 7252](https://www.rfc-editor.org/rfc/rfc7252)。
- **接入技术**：[Zigbee](https://csa-iot.org/all-solutions/zigbee/) 基于 IEEE 802.15.4，短距离、低功耗、支持网状组网，适合楼宇和室内局部网络；[NB-IoT](https://www.3gpp.org/technologies/nb-iot) 是 3GPP 标准化的蜂窝窄带物联网，使用运营商授权频谱，覆盖深、功耗低、速率低，适合广域分散的抄表类终端；[LoRa/LoRaWAN](https://lora-alliance.org/about-lorawan/) 工作在非授权的 Sub-GHz 频段，可自建网关，适合偏远区域、无运营商覆盖或希望自主组网的低速率场景。

### 高频考点题 6：设备归到哪一层

在一个配电台区监测系统中：①安装在变压器上的油温传感器；②负责把各终端数据传到主站的 5G 通信模块；③统一完成终端接入认证、数据汇聚和设备模型管理的物联管理平台；④给运维人员展示台区重过载预警的业务系统。按“感知层、网络层、平台层、应用层”四层划分，依次对应的是哪项？

- A. 感知层、网络层、平台层、应用层
- B. 感知层、平台层、网络层、应用层
- C. 网络层、感知层、应用层、平台层
- D. 感知层、网络层、应用层、应用层

**答案：A。** 采集、传输、接入与汇聚、业务服务依次对应四层。

**解析：** 传感器直接采集物理量，属感知层；5G 模块承担传输，属网络层；统一接入认证和数据汇聚是平台层的通用能力；预警展示面向运维业务，属应用层。B 把传输和平台颠倒；D 把通用平台并入应用层。

### 高频考点题 7：MQTT 的发布订阅

200 个智能电表通过 MQTT 上报数据，发布到主题 `meter/data`；主站分析程序与告警程序都订阅了该主题。下列说法正确的是哪项？

- A. 每个电表必须知道两个订阅程序的 IP 地址，并分别建立连接发送
- B. 电表把消息发布给代理，代理按主题转发给两个订阅者；若使用 QoS 1，订阅者可能收到重复消息，应用需能处理重复
- C. MQTT 运行在 UDP 上，因此天然不保证消息到达
- D. QoS 0 表示消息恰好送达一次，且开销最大

**答案：B。** 发布者与订阅者经代理按主题解耦，QoS 1 语义是至少一次。

**解析：** 发布/订阅模式中，发布者只与代理通信，不需要知道订阅者，A 描述的是点对点直连。MQTT 运行在 TCP 等有序可靠的传输上，运行在 UDP 上的是 CoAP，C 张冠李戴。QoS 0 是“最多一次”、开销最小，“恰好一次”是 QoS 2，D 错。

### 高频考点题 8：选哪种接入方式

某供电公司要在山区分散布置数百个杆塔倾斜监测终端：每个终端每小时上报几十字节，电池供电，部分点位没有运营商信号，公司希望自建网络。最合适的接入技术是哪项？

- A. Zigbee，因为它覆盖范围在几种技术中最大
- B. NB-IoT，因为它不依赖运营商网络
- C. LoRa/LoRaWAN，自建网关，在非授权 Sub-GHz 频段实现远距离、低功耗、低速率接入
- D. 光纤到每个杆塔，因为带宽最高

**答案：C。** 远距离、低功耗、无运营商覆盖、需自建网络，正符合 LoRa 的定位。

**解析：** Zigbee 单跳距离短，适合楼宇、站内局部组网，A 的理由不成立。NB-IoT 使用运营商授权频谱、依赖运营商基站，题设中部分点位没有信号，B 的理由恰好相反。D 的带宽远超需求，山区逐杆铺设光纤也不现实。

## 云计算、云边协同与并行加速

[NIST SP 800-145](https://csrc.nist.gov/pubs/sp/800/145/final) 定义了云计算的五个基本特征（按需自助服务、广泛网络访问、资源池化、快速弹性、可计量服务）、三种服务模式和四种部署模式（私有云、社区云、公有云、混合云）。服务模式的关键是“用户还要管什么”：

| 服务模式 | 云服务商提供到哪一层 | 用户仍需负责 |
| --- | --- | --- |
| IaaS | 计算、存储、网络等基础资源 | 操作系统、中间件、运行环境、应用、数据 |
| PaaS | 再加上操作系统与运行平台 | 自己部署的应用及其配置、数据 |
| SaaS | 完整应用 | 自己的数据、账号与应用内的少量用户级配置 |

**分布式计算**把任务拆到多台机器协作完成，要处理任务划分、数据分布和节点故障。**边缘计算**把计算放到靠近数据源的位置（站端、台区终端、边缘服务器）；**云边协同**则是分工：边缘侧负责低时延的实时处理、本地自治和数据过滤，云端负责大规模存储、全局分析和模型训练，再把模型、规则下发到边缘。**算力部署**要按时延、带宽、数据量和安全要求，在“端—边—云”之间安排计算位置。

**并行与异构计算。** CPU 核心少而强，擅长复杂控制流、分支和串行逻辑；GPU 有大量较简单的计算单元，擅长同一操作作用于大量数据的并行计算（矩阵运算、模型训练与推理、图像处理）。异构系统通常由 CPU 负责调度和串行部分，把可并行的计算卸载到 GPU 等加速器。

能加速多少，由 **Amdahl 定律**决定：设程序中可被加速部分占原执行时间的比例为 f，该部分加速 n 倍，则

> 加速比 S = 1 / [(1 − f) + f / n]，当 n → ∞ 时，S 的上限为 1 / (1 − f)。

串行部分是“天花板”：即使 f = 0.9，加速比也不会超过 10。存储层次等相关基础可回看站内的[计算机组成常考点](./soe-computer-organization.md)。

### 高频考点题 9：IaaS、PaaS、SaaS 谁负责什么

某单位租用云服务部署一个自研的工单系统。若采用 PaaS，下列哪项通常仍由该单位自己负责？

- A. 云数据中心机房供电与物理安保
- B. 运行平台所在的服务器硬件维护
- C. 自研工单系统的代码、配置及其业务数据
- D. 底层虚拟化层的补丁

**答案：C。** PaaS 下用户控制自己部署的应用及其配置和数据。

**解析：** 按 NIST SP 800-145，PaaS 用户不管理底层的网络、服务器、操作系统和存储，但控制自己部署的应用，并可能配置托管环境。A、B、D 都属于服务商负责的基础设施。

### 高频考点题 10：云边协同如何分工

某配电台区要求：开关异常时在 20 ms 内完成就地判断并闭锁；同时希望汇集全省台区数据训练故障识别模型，并每月更新模型。下列方案最合理的是哪项？

- A. 所有原始数据实时上传云端，由云端判断后再下发闭锁指令
- B. 全部在台区终端完成，包括全省数据的模型训练
- C. 边缘侧（台区终端）运行轻量模型做毫秒级就地判断和闭锁，上传筛选后的特征与事件；云端汇聚全省数据训练模型，并定期把新模型下发到边缘
- D. 只要采用公有云，网络时延就可以忽略

**答案：C。** 实时控制放在边缘，全局训练放在云端，模型由云下发到边，是云边协同的典型分工。

**解析：** A 的往返网络时延和云端排队都不可控，难以稳定满足 20 ms 要求。B 让单个终端承担全省数据训练，既拿不到全局数据，算力也不够。D 错在把部署模式与网络时延混为一谈，物理距离和网络路径带来的时延不会因为用了公有云而消失。

### 高频考点题 11：把可并行部分交给 GPU

某巡检图像分析程序在 CPU 上运行，其中 80% 的时间花在可并行的卷积计算上，其余 20% 为串行的读文件和后处理。把卷积部分迁移到 GPU 后，该部分提速 16 倍，串行部分不变。整体加速比和“卷积部分无限加速”时的理论上限分别是多少？

- A. 16 倍；无上限
- B. 4 倍；5 倍
- C. 12.8 倍；16 倍
- D. 3.2 倍；4 倍

**答案：B。** S = 1 / (0.2 + 0.8 / 16) = 4；上限 1 / 0.2 = 5。

**解析：** 设原耗时为 1，迁移后耗时 = 0.2 + 0.8 / 16 = 0.2 + 0.05 = 0.25，加速比 1 / 0.25 = 4。卷积部分无限加速时耗时趋于 0.2，上限为 5。A 只看了局部提速倍数，忽略了串行部分；C 是把 0.8 × 16 当成加速比，公式不成立；D 的 3.2 是 16 × 0.2，把局部提速倍数乘上串行比例，没有物理意义；它给的上限 4 也不对：卷积部分只提速 16 倍时整体已达 4 倍（耗时 0.25），无限加速时耗时继续降到 0.2，加速比只能更大，应为 5。

## 大数据：从采集到挖掘，再到安全防护

大数据通常用 5V 概括：**Volume**（体量大）、**Velocity**（产生和处理速度快）、**Variety**（结构化、半结构化、非结构化并存）、**Value**（价值密度低）、**Veracity**（数据质量与可信度参差）。不同资料对第五个 V 的取舍略有差异，[NIST 大数据互操作框架第 1 卷](https://www.nist.gov/publications/nist-big-data-interoperability-framework-volume-1-definitions)以体量、速度、多样性、可变性为核心特征。

一条典型的处理链路：

1. **采集**：传感器与终端上报、日志采集、数据库同步、消息队列接入；按时效分为批量采集和实时流式采集。批处理与流处理的区别见站内的[批处理与流处理](../../knowledge/data/pipeline/batch-stream-processing.md)。
2. **预处理**：清洗（去重、纠错、剔除明显异常）、缺失值处理（删除、均值/中位数填补、插值）、变换（归一化、标准化、离散化）、集成与规约。最小—最大归一化 x' = (x − min) / (max − min) 把数据映射到 [0, 1]；Z-score 标准化 z = (x − μ) / σ 让数据均值为 0、标准差为 1。见 [scikit-learn 预处理文档](https://scikit-learn.org/stable/modules/preprocessing.html)。数据质量检查可参考站内的[数据质量](../../knowledge/data/processing/data-quality.md)。
3. **存储与分析**：分布式文件系统与 NoSQL 存放海量数据。[MapReduce](https://research.google/pubs/mapreduce-simplified-data-processing-on-large-clusters/) 把计算拆为 Map（把输入转成键值对）和 Reduce（对同一键的值做汇总），中间由框架完成按键分组的 Shuffle。例如统计告警类型次数：Map 对每条记录输出 (类型, 1)，Shuffle 后同类型的 1 被送到同一个 Reduce 求和。
4. **数据模型**：关系模型适合结构化事务数据；键值、文档、列族、图模型分别适合高速读写、半结构化记录、海量宽表和关系网络（如电网拓扑）。
5. **挖掘**：分类、聚类、关联规则、异常检测、时间序列预测。关联规则用支持度（同时出现的比例）和置信度（出现 A 时也出现 B 的比例）衡量。
6. **可视化**：趋势用折线图，类别比较用柱状图，分布用直方图或箱线图。
7. **安全防护**：分级分类、访问控制与最小权限、传输和存储加密、操作审计，以及对个人信息和敏感数据的**脱敏**。《个人信息保护法》区分“去标识化”（不借助额外信息无法识别特定个人）和“匿名化”（无法识别且不能复原）；去标识化后的数据仍属于个人信息。[NIST SP 800-188](https://csrc.nist.gov/pubs/sp/800/188/final) 讨论了去标识化后的重识别风险。

### 高频考点题 12：先填补缺失值，再归一化

某监测点 5 次温度读数为 20、50、缺失、80、120（单位 ℃）。先用其余已观测值的**均值**填补缺失值，再对这 5 个数做最小—最大归一化。填补值归一化后的结果是多少？

- A. 0.45
- B. 0.475
- C. 0.675
- D. 0.5

**答案：B。** 填补值为 67.5，(67.5 − 20) / (120 − 20) = 0.475。

**解析：** 已观测值的均值 = (20 + 50 + 80 + 120) / 4 = 67.5；填补后最小值仍为 20，最大值为 120。归一化结果 = (67.5 − 20) / 100 = 0.475。A 是用中位数 (50 + 80) / 2 = 65 填补得到的 (65 − 20) / 100，与题设的均值填补不符；C 直接用 67.5 / 100，漏减最小值；D 是区间中点的直觉值，没有计算依据。
