想用计算机、软件、电子信息这类专业考国考，第一个问题不是“怎么备考”，而是“到底有多少岗位真的写了我的专业，它们分布在哪”。本文只用 2027 年度国考职位表回答这个问题。想直接按自己的条件筛，用站内的 [2027 国考职位筛选](https://www.agent-journey.cn/civil/positions)。

## 一句话结论

- 专业要求里出现计算机、软件、网络空间安全、信息安全、数据科学、人工智能、电子信息、信息与通信、通信工程等写法的职位共 **4754 个、招 8581 人**，约占全部招录人数的四分之一。
- 这些岗位**绝大多数在基层**：县（区）级及以下 3622 个职位（6768 人），中央本级只有 81 个职位（140 人）。
- **税务系统是绝对主力**：国家税务总局系统 2980 个职位、6120 人，超过技术类招录人数的七成。
- **应届身份很值钱**：大量职位在备注里限招应届，同样的专业和学历，应届与往届能报的职位数差距很大，可以在[职位筛选器](https://www.agent-journey.cn/civil/positions)里切换“是否应届”对比。

## 1. 岗位在哪一层、考哪类卷

国考公共科目试卷分三类，对应不同的职位类别；报哪类职位，就考哪类卷。技术类职位的分布如下：

| 考试类别 | 职位数 | 招录人数 |
| --- | ---: | ---: |
| 行政执法类 | 3456 | 6937 |
| 市（地）级及以下直属机构综合管理类 | 1041 | 1213 |
| 中央机关及其省级直属机构综合管理类 | 257 | 431 |

| 机构层级 | 职位数 | 招录人数 |
| --- | ---: | ---: |
| 县（区）级及以下 | 3622 | 6768 |
| 市（地）级 | 867 | 1369 |
| 省（副省）级 | 184 | 304 |
| 中央 | 81 | 140 |

读法：如果你的目标是“在北京的部委做信息化”，可选的盘子只有一百来个职位；如果接受去地市、区县，盘子大几十倍。这和公告里的招录原则一致：中央机关及其省级直属机构主要招有 2 年以上基层工作经历的人，市（地）级及以下直属机构主要招应届高校毕业生。

## 2. 哪些系统在招

| 系统（按部门名称归并） | 职位数 | 招录人数 |
| --- | ---: | ---: |
| 国家税务总局系统 | 2980 | 6120 |
| 中国人民银行系统 | 305 | 436 |
| 国家统计局系统（含各地调查队） | 229 | 234 |
| 金融监管总局系统（职位属性为“金融监管”各类） | 451 | 522 |
| 海关、出入境边防检查、铁路公安等 | 余下部分 | — |

上表金融监管一行按职位属性统计，包括计算机类、综合类、财经类、法律类。其中“金融监管计算机类职位”是单独标出的一种属性，共 398 个职位、459 人；证监会另有“证监计算机类职位”15 个、21 人。这两类职位除公共科目外，**还要考专业科目**，笔试成绩按行测、申论、专业科目 25%、25%、50% 合成（见公告“三、考试内容、时间和地点”）。

税务系统岗位多，但要注意：很多税务职位的专业要求是“财政学类、经济学类、计算机类……”这样的多类并列，岗位本身多为综合执法或征管，不一定是纯技术岗。看职位简介比看专业更能判断日常做什么。

## 3. 门槛主要卡在哪

以下比例针对 4754 个技术类职位：

| 条件 | 情况 |
| --- | --- |
| 学历 | “本科及以上”3363 个，“仅限本科”742 个；明确要硕士及以上的 396 个，仅限硕士 93 个 |
| 政治面貌 | 不限 4161 个；要求中共党员 299 个；中共党员或共青团员 294 个 |
| 基层工作经历 | 无限制 3565 个；有年限要求 1189 个 |
| 应届身份 | 很大一部分职位在备注里写明只招应届（如“限 2027 届高校毕业生”），写法不统一，具体以每个职位的备注原文为准 |
| 地区类别 | 西部地区和艰苦边远地区职位 1767 个 |

这些条件叠起来，不同身份能报的职位数差别很大。你自己的情况可以在本站[职位筛选器](https://www.agent-journey.cn/civil/positions)里按专业、学历、政治面貌、基层年限、是否应届初筛一遍。筛选器只按文字做初筛，不是资格审查结论。

两个容易被忽略的点：

1. **应届身份比政治面貌影响大**。大量职位限招应届，在筛选器里切换“是否应届”，能报的职位数变化远大于切换政治面貌。另外，应届身份不是只有毕业当年才有：按《报考指南》，择业期内（毕业后两年内）未落实工作单位、户口档案组织关系仍保留在学校或人才、就业服务机构的毕业生，也可按应届身份报考。具体认定以当年《报考指南》和职位备注为准。
2. **硕士不一定比本科能报的多**。很多职位写“仅限本科”或“本科或硕士研究生”，研究生段又常写一级学科名称（如 0812 计算机科学与技术），和本科专业类的写法不同，要逐条看原文。

## 4. 地区分布

技术类职位招录人数最多的十个省级地区：广东（761 人）、山东（543）、河北（526）、四川（476）、河南（441）、辽宁（440）、湖北（402）、内蒙古（397）、云南（392）、黑龙江（385）。国考职位按招录机关所在地分布，和省考的地区分布不是一回事。

## 5. 现在还能做什么

2027 年度国考提交报考申请已在 2026 年 10 月 24 日截止，报名确认缴费在 11 月 6 日截止，公共科目笔试在 11 月 29 日。这份职位表现在还有两个用处：

- **调剂（只对已参加笔试的人）**：公告规定，达到笔试合格分数线的人数与计划录用人数之比低于面试比例的职位，会面向社会调剂，调剂在答同一类试卷的职位之间进行。调剂的对象是参加了本次笔试、成绩达到合格分数线的报考者。**没有完成注册认证、提交报考申请和报名确认缴费的人，不能通过调剂补报名。** 笔试成绩预计 2027 年 1 月公布，调剂公告届时在专题网站发布，具体条件以调剂公告为准。
- **为下一次做准备**：看清国考职位的专业写法、应届限制和系统分布，可以提前判断自己该准备哪类试卷。下一年度的职位以届时公布的职位表为准，本文只统计 2027 年度。

## 统计口径

- “技术类职位”：职位表“专业”一栏出现计算机、软件、网络空间安全、信息安全、网络工程、大数据、数据科学、人工智能、电子信息、信息与通信、通信工程中任一写法，或职位属性含“计算机”。专业栏同时列了多个大类的职位也计入，专业范围也包含电子信息、通信等，所以它反映的是“计算机、电子信息、通信等相关专业有机会报”，不等于“计算机类专业都能报”，更不等于“岗位内容是技术工作”。
- 本站职位筛选器是按专业名称、专业类、研究生学科名称做的文字初筛，不是资格审查结论。专业是否符合，以《招考简章》和招录机关解释为准；拿不准时打职位表上的咨询电话。
