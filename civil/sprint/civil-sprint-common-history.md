**这类题考什么：** 常识判断里的历史人文题，以中国古代史为主：朝代顺序、重要制度的起源、科技成就的年代、文化常识。和时政不同，这部分内容多年不变，背一次能用很多年。考法通常是「下列说法正确 / 错误的是」，所以重点是**把时间和事件对上号**。

本文内容均为中学历史教材的基础知识。

## 朝代顺序：一条主线

**夏 → 商 → 西周 → 东周（春秋、战国）→ 秦 → 西汉 → 东汉 → 三国 → 西晋 → 东晋与十六国 → 南北朝 → 隋 → 唐 → 五代十国 → 北宋（与辽、西夏并立）→ 南宋（与金并立）→ 元 → 明 → 清。**

考场上最常用的是判断「两件事谁先谁后」，只要把事件挂到朝代上，按这条主线比较即可。

## 政治制度：起源时间速查

| 制度 | 出现时间 | 一句话 |
| --- | --- | --- |
| 郡县制 | 秦朝在全国推行 | 地方官由皇帝任免，不再世袭 |
| 科举制 | 隋朝创立，唐朝完善 | 分科考试选拔官员，打破门第限制 |
| 三省六部制 | 隋朝确立，唐朝完善 | 中书省起草、门下省审议、尚书省执行 |
| 行省制度 | 元朝 | 我国省级行政区划的开端 |
| 废除丞相 | 明朝朱元璋 | 皇权进一步集中 |
| 军机处 | 清朝雍正年间设立 | 君主专制发展到顶峰的标志 |

| 成就 | 时间与人物 |

## 文化常识：几组容易混的称呼

- **科举名次（明清）**：乡试第一名称**解元**，会试第一名称**会元**，殿试一甲第一名称**状元**、第二名**榜眼**、第三名**探花**。
- **唐宋八大家**：唐代韩愈、柳宗元；宋代欧阳修、苏洵、苏轼、苏辙、王安石、曾巩。共 8 人，唐 2 宋 6。
- **「三苏」**：苏洵与儿子苏轼、苏辙。
- **四书**：《大学》《中庸》《论语》《孟子》；**五经**：《诗》《书》《礼》《易》《春秋》。

## 高频考点练习

### 高频考点题 1：制度起源

下列关于我国古代政治制度的说法，**错误**的是：

- A. 秦朝在全国推行郡县制
- B. 科举制创立于唐朝
- C. 行省制度始于元朝
- D. 清朝雍正年间设立军机处

**答案：B。**

**解析：** 科举制创立于隋朝，唐朝加以完善。B 把创立和完善混在一起，是最常见的设错方式。其余三项都正确。

### 高频考点题 2：科技成就与朝代

下列科技成就按出现时间先后排列，正确的是：

① 毕昇发明活字印刷　② 蔡伦改进造纸术　③ 祖冲之把圆周率精确到小数点后第七位

- A. ②③①
- B. ①②③
- C. ③②①
- D. ②①③

**答案：A。**

**解析：** 蔡伦是东汉人，祖冲之是南朝人，毕昇是北宋人。按「东汉 → 南北朝 → 北宋」排列，是 ②③①。

### 高频考点题 3：科举名次

某人在明代科举中先后获得乡试第一名和会试第一名，按当时的称呼，他先后被称为：

- A. 状元、榜眼
- B. 解元、会元
- C. 会元、解元
- D. 解元、状元

**答案：B。**

**解析：** 乡试第一名称解元，会试第一名称会元，殿试一甲第一名才称状元。连中「解元、会元、状元」被称为「连中三元」。

### 高频考点题 4：唐宋八大家

下列人物中，**不属于**「唐宋八大家」的是：

- A. 柳宗元
- B. 曾巩
- C. 李白
- D. 王安石

**答案：C。**

**解析：** 唐宋八大家是以散文著称的八位作家，唐代只有韩愈和柳宗元两位。李白是唐代诗人，不在其中。

### 高频考点题 5：三省六部

在隋唐的三省六部制中，负责**审议**诏令、可以驳回不合适诏令的是：

- A. 中书省
- B. 门下省
- C. 尚书省
- D. 吏部

**答案：B。**

**解析：** 中书省负责起草诏令，门下省负责审议，尚书省负责执行，六部隶属尚书省。D 是尚书省下设的六部之一，主管官员任免考核。

## 常见陷阱

1. **「创立」和「完善」混用。** 科举制、三省六部制都是隋朝创立、唐朝完善，题目最爱在这里设错。
2. **「发明」和「改进」混用。** 蔡伦是改进造纸术，不是发明造纸术。
3. **「出现」和「应用」混用。** 指南针战国就有雏形，用于航海是宋代；火药的配方唐代已有记载，用于军事是唐朝末年。
4. **人物朝代张冠李戴。** 记人物时顺手记一个朝代，比记具体年份有效得多。
