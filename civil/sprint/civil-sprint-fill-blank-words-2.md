**这类题考什么：** 接着《逻辑填空：易混实词与易错成语》整理第二组高频易混词和易错成语。做法一样：先看两个词差在哪个字，再看这个字决定了用在什么对象、什么场合。

词义以《现代汉语词典》的通行释义为准。

## 一、易混实词（第二组）

| 词语 | 区别 | 例句 |
| --- | --- | --- |
| 考查 / 考察 | 「考查」是用一定标准来检查衡量，多用于学业、能力；「考察」是实地观察调查，或者细致深刻地观察 | 考查学生的阅读能力。到基层考察产业项目。 |
| 度过 / 渡过 | 「度过」用于时间；「渡过」用于江河，也用于比喻通过难关、危机 | 度过了愉快的假期。渡过难关。 |
| 法制 / 法治 | 「法制」指法律制度；「法治」指依法治理，和「人治」相对 | 健全法制。建设法治中国。 |
| 检查 / 检察 | 「检查」用途很广，指查看、找问题；「检察」专指审查被检举的犯罪事实，多用于检察机关 | 检查卫生。人民检察院。 |
| 期间 / 其间 | 「期间」指某个时期里面，前面一般要有限定词；「其间」意思是「那中间」，指代前文说过的一段时间或范围 | 会议期间。他离家十年，其间只回来过两次。 |
| 质疑 / 置疑 | 「质疑」是提出疑问；「置疑」是怀疑，多用于否定 | 对结论提出质疑。不容置疑。 |
| 申明 / 声明 | 「申明」是郑重说明理由、立场；「声明」是公开表示态度或说明真相，也指这样的文告 | 申明理由。发表声明。 |
| 委屈 / 委曲 | 「委屈」是受到不应有的指责或待遇，心里难过；「委曲」是曲折，或者勉强迁就（委曲求全） | 受了委屈。委曲求全。 |

## 二、易错成语（第二组）

| 成语 | 正确含义 | 常见误用 |
| --- | --- | --- |
| 万人空巷 | 家家户户的人都从巷子里出来了，形容庆祝、欢迎等盛况 | 误当成「街上空无一人」 |
| 登堂入室 | 比喻学问或技能由浅入深，达到很高的水平 | 误用于字面意思「走进屋里」 |
| 目无全牛 | 形容技艺纯熟到了得心应手的境地 | 误当成「看问题缺乏全局观」 |
| 罄竹难书 | 形容罪行多得写不完，贬义 | 误用于形容功绩、好事多 |
| 蓬荜生辉 | 谦辞，表示别人到自己家里来或张挂别人的字画，使自己感到很光荣 | 误用于称赞别人的家 |
| 期期艾艾 | 形容口吃 | 误当成「哀怨、凄凉」 |
| 望其项背 | 能够望见别人的颈项和脊背，表示赶得上，多用于否定形式「难以望其项背」 | 误用于肯定句，表示「远远落后」 |
| 求全责备 | 对人对事要求十全十美，毫无缺点 | 误当成「责备、批评」 |

## 高频考点练习

### 高频考点题 1：考查 / 考察

填入下面句子画横线处最恰当的一项是：

调研组一行深入园区，实地________了当地的生态修复项目，并听取了企业负责人的情况介绍。

- A. 考查
- B. 审查
- C. 考察
- D. 检察

**答案：C。**

**解析：** 句中有「实地」「深入园区」，是到现场观察调查，用「考察」。「考查」用于按标准检查衡量学业、能力；「审查」是检查核对是否正确、妥当，多用于计划、资格、材料；「检察」专指检察机关审查犯罪事实。

### 高频考点题 2：度过 / 渡过

填入下面句子画横线处最恰当的一项是：

老校长在这所山村小学________了自己的整个青年时代，培养了一批又一批学生。

- A. 渡过
- B. 度过
- C. 越过
- D. 穿过

**答案：B。**

**解析：** 「青年时代」是一段时间，用「度过」。「渡过」用于江河或难关；「越过」「穿过」都是空间上从一处到另一处，不能和「青年时代」搭配。

### 高频考点题 3：法制 / 法治

填入下面句子画横线处最恰当的一项是：

坚持全面依法治国，推进________中国建设，让人民群众在每一项法律制度、每一个执法决定、每一宗司法案件中都感受到公平正义。

- A. 法律
- B. 法规
- C. 法制
- D. 法治

**答案：D。**

**解析：** 「全面依法治国」讲的是依法治理，对应「法治」，固定表述是「法治中国」。「法制」指法律制度本身；「法律」「法规」都是具体的规范，不能和「中国建设」搭配成这个意思。

### 高频考点题 4：其间 / 期间

填入下面句子画横线处最恰当的一项是：

他 2019 年离开家乡外出闯荡，________只回过两次家，每次都待不满一周。

- A. 其间
- B. 期间
- C. 时期
- D. 时间

**答案：A。**

**解析：** 空格前面没有限定词，要指代前文「离开家乡外出闯荡」以来的这段时间，用「其间」，意思是「那中间」。「期间」前面一般要有限定，如「闯荡期间」；「时期」「时间」单独放在句首也说不通。

### 高频考点题 5：成语使用

下列句子中，加粗的成语使用**正确**的一项是：

- A. 春节假期城里人大多回了老家，往日热闹的商业街**万人空巷**，冷冷清清。
- B. 冠军队凯旋那天，城里**万人空巷**，市民们涌上街头夹道欢迎。
- C. 他刚学书法半年，作品就**登堂入室**地摆进了市里的展厅。
- D. 这位老人几十年如一日资助贫困学生，善举**罄竹难书**。

**答案：B。**

**解析：** 「万人空巷」形容人们都从家里出来，聚到街上，是盛况，B 正确；A 把它理解成「街上没人」，正好用反了。C「登堂入室」指学问技能达到很高水平，不是「走进展厅」的字面意思。D「罄竹难书」是贬义，形容罪行多，不能用于善举。

## 常见陷阱

1. **只看词义，不看搭配对象。** 「度过」接时间，「渡过」接难关；「考查」接能力，「考察」接现场。对象一换，答案就换。
2. **「期间」和「其间」凭语感选。** 先看空格前面有没有限定词：有限定词用「期间」，没有、而是指代前文的，用「其间」。
3. **成语按字面理解。** 「万人空巷」「登堂入室」「目无全牛」都是字面和真实含义相差很远的，最容易设错。
4. **褒贬用反。** 「罄竹难书」只能用于坏事，「蓬荜生辉」只能说自己家。

## 冲刺建议

- 两篇的易混词合起来三十多组，考前每天花 10 分钟过一遍表格，重点记「对象」那一列。
- 做题时遇到两个选项是易混词，先回到句子里找它的搭配对象，比凭语感快也准。
