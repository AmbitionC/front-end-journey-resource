**这类题考什么：** 判断推理里，定义判断和类比推理是两个「拿分快」的模块。定义判断给你一个新概念，问哪个选项符合或不符合；类比推理给你一组词，让你找出关系最相近的另一组。两者考的都是**按规则对照**，不需要专业知识，最怕的是凭感觉选。

## 识别信号与做法

| 题型 | 题干特征 | 做法 |
| --- | --- | --- |
| 定义判断：选「属于」 | 「下列属于××的是」 | 拆出定义的关键要素，**逐条**核对选项，全部满足才选 |
| 定义判断：选「不属于」 | 「下列不属于××的是」 | 找出**违反某一条要素**的选项 |
| 类比：种属 / 包含 | 前一个是后一个中的一种 | 看是「一种」还是「一部分」，二者不能混 |
| 类比：组成 | 前一个是后一个的组成部分 | 同上，注意和种属区分 |
| 类比：功能 / 依存 | 一个东西要靠另一个才能发挥作用 | 确认依存的方向和方式（消耗品、动力、载体） |
| 类比：职业与产出 | 某种职业和它的工作对象、场所、成果 | 看清对应的是对象、场所还是成果 |

## 方法步骤

**定义判断：**

1. 读定义时，把**主体、行为、目的、条件、结果**这几类要素拆出来，用笔圈出限定词（如「在……之前」「家庭中」「主动」）。
2. 拿每个选项去对照要素。限定词往往就是出题人设陷阱的地方。
3. 选「不属于」时，只要找到一条不满足就可以定答案。

**类比推理：**

1. 先用一句话把题干两个词的关系说出来，例如「钢笔要靠墨水才能写字」。
2. 把这句话里的词换成选项的词，读得通的留下。
3. 剩下不止一个时，再看第二层关系：方向是否一致、是否都是必要条件、词性是否相同。

## 高频考点练习
### 高频考点题 1：定义判断（属于）

**数字反哺**是指在家庭中，年轻一代主动向年长一代传授使用智能设备和网络应用的知识与技能，帮助长辈适应数字生活的现象。

下列属于数字反哺的是：

- A. 社区志愿者每周到养老院教老人用手机挂号
- B. 公司组织中老年员工参加办公软件培训
- C. 小王的女儿手把手教奶奶用视频通话联系远方亲戚
- D. 老张在家教上初中的儿子用电脑制作表格

**答案：C。**

**解析：** 定义有三个要素：发生在家庭中；由年轻一代教年长一代；内容是数字技能。C 三条都满足。A 的志愿者和老人不是家庭关系；B 是单位培训，也不在家庭中；D 方向反了，是长辈教晚辈。

### 高频考点题 2：定义判断（不属于）

**预防性维护**是指在设备发生故障**之前**，按照计划定期进行检查、保养或更换零部件，以降低故障发生的概率、延长设备使用寿命。

下列不属于预防性维护的是：

- A. 私家车每行驶 5000 公里更换一次机油
- B. 物业每半个月对小区电梯进行一次例行检查
- C. 办公室打印机卡纸后，行政人员拆开清理了进纸轮
- D. 进入雨季前，街道提前疏通了辖区内的排水管道

**答案：C。**

**解析：** 关键限定词是「故障发生之前」和「按计划」。A、B、D 都是在问题出现前按里程、周期或季节安排的保养。C 是卡纸**已经发生之后**的处理，属于事后维修，不符合定义。

### 高频考点题 3：类比推理（功能依存）

钢笔 : 墨水

- A. 台灯 : 灯罩
- B. 汽车 : 汽油
- C. 书包 : 课本
- D. 相机 : 照片

**答案：B。**

**解析：** 钢笔要消耗墨水才能书写，墨水用完要补充。汽车要消耗汽油才能行驶，关系一致。A 的灯罩是台灯的组成部分，不会被消耗；C 是容器和所装物品；D 的照片是相机的产出，不是它工作时消耗的东西。

### 高频考点题 4：类比推理（职业与成果）

教师 : 教案

- A. 记者 : 新闻稿
- B. 医生 : 病人
- C. 厨师 : 厨房
- D. 演员 : 观众

**答案：A。**

**解析：** 教案是教师在工作中撰写的文本，属于「职业和它写出的文字成果」。记者撰写新闻稿，关系一致。B、D 是职业和服务对象；C 是职业和工作场所。

### 高频考点题 5：类比推理（种属）

苹果 : 水果

- A. 课桌 : 教室
- B. 松树 : 树木
- C. 轮胎 : 汽车
- D. 钢琴 : 琴键

**答案：B。**

**解析：** 苹果是水果的一种，属于种属关系。松树是树木的一种，关系一致。A 是物品和它所在的场所；C 是组成关系，轮胎是汽车的一部分，而不是「一种」汽车；D 也是整体和部分，并且方向反了。

## 常见陷阱

1. **只核对了一个要素就选。** 定义判断的干扰项通常满足大部分要素，只在一个限定词上出错。
2. **主体或方向看反。** 「年轻一代教年长一代」和「长辈教晚辈」只差一个方向。
3. **种属和组成混在一起。** 「是一种」和「是一部分」是两种不同的关系。
4. **类比只看表面联系。** 词语之间有联系不等于关系相同，一定要先把关系用一句话说出来。

## 冲刺建议

- 定义判断每题控制在 40 秒左右：先圈限定词，再对选项。
- 类比推理遇到两个选项都说得通，就比第二层关系，不要凭语感选。
- 平时练习时，把常见的类比关系（种属、组成、功能、因果、职业对象）整理成一页，考前过一遍。
