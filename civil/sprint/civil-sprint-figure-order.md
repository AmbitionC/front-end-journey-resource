> 本文例题均为原创模拟题，图形由本站程序绘制。

**这类题考什么：** 给一组图形，找出其中的规律，再从四个选项里选出符合规律的一个。规律种类很多，但考场上没时间逐个试。关键是**按固定顺序排查**：先看最容易一眼看出的特征，看不出再往下换。

## 排查顺序：位置 → 对称 → 数量 → 样式 → 属性

| 顺序 | 看什么 | 什么时候优先想到它 |
| --- | --- | --- |
| 1. 位置 | 某个元素在平移、旋转、翻转 | 每幅图的元素相同、只是位置不同 |
| 2. 对称 | 是否对称、对称轴的方向和条数 | 每幅图都很规整，像几何课本上的图形 |
| 3. 数量 | 面（封闭区域）、线、笔画、交点、元素个数 | 每幅图的元素各不相同、看不出关系 |
| 4. 样式 | 黑白叠加、去同存异、求同存异 | 每幅图的轮廓相同，内部的黑白或线条在变 |
| 5. 属性 | 曲直、开闭 | 前面几种都看不出规律时再想 |

**一个经验：** 每幅图的元素「长得一样」，先看位置；「组成相似、细节不同」，先看样式；「完全不同」，先看数量。数量规律另有一篇专门讲。

## 方法步骤

1. **扫一眼（5 秒）：** 判断属于上表哪种情形，决定先看什么。
2. **验证（20 秒）：** 用前两三幅图提出规律，再用第四幅图验证。
3. **代入（10 秒）：** 推出问号处应该是什么样，在选项里找。找不到唯一答案，说明规律找错了，回到第 1 步换下一种。

### 原创模拟题 3：样式：黑白叠加，同白异黑

![黑白样式规律题：2×2 方格，第一组前两幅叠加后，相同颜色的格子变白，不同的变黑，得到第三幅；第二组需按同样规律求第三幅](https://font-end-journey-resources.oss-cn-hangzhou.aliyuncs.com/images/civil-sprint-figure-blackwhite-v1.png)

- A
- B
- C
- D

**答案：A。**

**解析：** 每幅图的轮廓相同，都是 2×2 的方格，只有黑白在变，所以看样式。在第一组里，把前两幅图逐格对比：颜色相同的格子变白，颜色不同的格子变黑，这就是第三幅（同白异黑）。第二组按同样规律：左上都是白，变白；右上都是黑，变白；左下一黑一白，变黑；右下一白一黑，变黑。结果是下面一行黑，选 A。B 是「有黑就黑」，C 是「都黑才黑」，D 是 A 的黑白反转。

## 常见陷阱

1. **一上来就数数。** 数量规律最费时间，应该在位置、对称都排除以后再数。
2. **只验证了前两幅。** 规律至少要用三幅图验证，否则很容易碰巧成立。
3. **把旋转当成翻转。** 旋转后，图形里的元素沿顺时针排列的顺序不变；翻转后，这个顺序会反过来。
4. **位置题只追一个元素。** 有两个元素时，它们可能各自走不同的方向和步数，要分开追踪。

## 冲刺建议

- 图形推理单题建议 45 秒以内。按上面的顺序排查两轮还看不出规律，就随便选一个并标记，然后继续往下做。
- 考前两周，把错题按「位置、对称、数量、样式、属性」归类。哪一类错得多，就专门练那一类的识别信号。
- 分组分类题（把六幅图分成两组）同样适用这个顺序，只是要找的是「三幅一样、另外三幅一样」的共同点。
