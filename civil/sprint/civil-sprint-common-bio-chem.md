**这类题考什么：** 常识判断里的科技题，除了物理（见《常识判断：光学与物态变化》），最常考的是**生物和化学的生活常识**：缺了哪种营养素会得什么病、身体里各部分负责什么、厨房和家里的化学现象。题目通常是「下列说法正确 / 错误的是」，几个选项分别来自不同领域，所以重点是把**对应关系**记准。

本文内容均为初中生物、化学教材的基础知识。

## 一、营养素缺乏症

| 缺乏 | 可能导致 | 常见来源 |
| --- | --- | --- |
| 维生素 A | 夜盲症 | 动物肝脏、胡萝卜 |
| 维生素 B1 | 脚气病（不是「脚气」那种真菌感染） | 谷物的外皮、豆类 |
| 维生素 C | 坏血病 | 新鲜蔬菜、水果 |
| 维生素 D | 儿童佝偻病、成人骨质疏松 | 晒太阳、蛋黄 |
| 碘 | 地方性甲状腺肿（大脖子病） | 海带、加碘盐 |
| 铁 | 缺铁性贫血 | 瘦肉、动物血 |

## 二、血液的组成

| 成分 | 主要功能 |
| --- | --- |
| 红细胞 | 运输氧气（靠其中的血红蛋白） |
| 白细胞 | 吞噬病菌，防御疾病 |
| 血小板 | 止血和加速凝血 |
| 血浆 | 运载血细胞，运输营养物质和废物 |

**一氧化碳中毒（煤气中毒）** 的原因：一氧化碳与血红蛋白结合的能力远强于氧气，导致血液不能正常运输氧气。

## 三、光合作用与呼吸作用

- **光合作用：** 绿色植物在叶绿体里，利用光能把二氧化碳和水合成有机物，并释放氧气。必须有光。
- **呼吸作用：** 生物把有机物分解成二氧化碳和水，释放能量。有光无光都在进行。

## 四、家里的化学

| 现象 / 做法 | 原理 |
| --- | --- |
| 用食醋除水垢 | 水垢的主要成分碳酸钙能与醋中的醋酸反应 |
| 发面时加小苏打 | 小苏打（碳酸氢钠）受热或遇酸产生二氧化碳，使面团疏松 |
| 被蚊虫叮咬后涂肥皂水 | 叮咬注入的酸性物质被碱性的肥皂水中和，减轻痛痒 |
| 铁锅生锈 | 铁与空气中的氧气和水同时接触才会生锈；擦干、抹油能防锈 |
| 不能用钢丝球擦铝锅 | 铝表面有一层致密的氧化膜保护内部，擦掉会加快腐蚀 |

## 高频考点练习

### 高频考点题 1：缺乏症

下列营养素与缺乏症的对应，**错误**的是：

- A. 缺维生素 A——夜盲症
- B. 缺维生素 C——坏血病
- C. 缺碘——佝偻病
- D. 缺铁——缺铁性贫血

**答案：C。**

**解析：** 缺碘导致地方性甲状腺肿，佝偻病是儿童缺维生素 D（或钙）导致的。其余三项都正确。

### 高频考点题 2：血液

人体血液中负责运输氧气的是：

- A. 白细胞
- B. 血小板
- C. 红细胞
- D. 血浆

**答案：C。**

**解析：** 红细胞中的血红蛋白能与氧气结合，负责运输氧气。白细胞负责防御，血小板负责止血凝血，血浆主要运载血细胞和营养物质。

### 高频考点题 3：煤气中毒

冬季在密闭房间里用炭火取暖容易发生中毒，主要原因是：

- A. 炭火燃烧消耗了全部氧气
- B. 燃烧产生的一氧化碳与血红蛋白结合，使血液运输氧气的能力下降
- C. 燃烧产生的二氧化碳有剧毒
- D. 炭火使室内温度过高

**答案：B。**

**解析：** 不完全燃烧产生的一氧化碳与血红蛋白的结合能力远强于氧气，使人体缺氧。A 夸大了，房间里的氧气不会被「全部」消耗；C 错在二氧化碳本身没有剧毒；D 与中毒无关。

### 高频考点题 4：家里的化学

下列生活做法与原理的对应，**正确**的是：

- A. 用食醋除水垢——醋酸能与碳酸钙反应
- B. 用钢丝球擦铝锅——能去掉铝锅表面的保护膜，延长使用寿命
- C. 发面加小苏打——小苏打能杀灭面团里的细菌
- D. 铁锅洗后不擦干——水能隔绝空气，防止生锈

**答案：A。**

**解析：** 水垢的主要成分碳酸钙能与醋酸反应，所以食醋能除水垢。B 擦掉氧化膜会加快腐蚀；C 小苏打的作用是产生二氧化碳使面团疏松，不是杀菌；D 铁同时接触水和氧气才生锈，不擦干反而容易生锈。

### 高频考点题 5：光合作用

下列关于光合作用的说法，**正确**的是：

- A. 光合作用在夜晚也能正常进行
- B. 光合作用吸收氧气，释放二氧化碳
- C. 光合作用主要在叶绿体中进行，产物是有机物和氧气
- D. 只有动物才进行呼吸作用，植物不进行

**答案：C。**

**解析：** 光合作用在叶绿体中利用光能，把二氧化碳和水合成有机物，释放氧气。A 错，光合作用需要光；B 把原料和产物说反了；D 错，植物也一直在进行呼吸作用。

## 常见陷阱

1. **把「脚气病」当成「脚气」。** 脚气病是缺维生素 B1 引起的，「脚气」是真菌感染，两回事。
2. **光合作用和呼吸作用的原料、产物说反。** 光合作用吸收二氧化碳、放出氧气；呼吸作用正好相反。
3. **把二氧化碳和一氧化碳混为一谈。** 煤气中毒是一氧化碳。

## 冲刺建议

- 这类题每题 30 秒内完成。考前把四张表各看一遍，重点看「缺乏症」和「家里的化学」。
- 选项里出现「全部」「一定」「只有」这类绝对化表述时，优先怀疑它是错误选项。
