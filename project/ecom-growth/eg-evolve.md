前面的环节各自完成了一件事。这一章把它们接成闭环：读归因结论，淘汰差的素材，改写好的素材，重新送审，进入下一轮。它是「Agent 评测与自进化平台」项目里“读反馈、改写、验证”那套方法在一个业务场景里的应用。

## 一轮进化做三件事

*淘汰直接作用在候选集合上，改写和补缺出来的新素材必须先过审核。*

## 淘汰

淘汰用规则判定，不交给模型：

```python
def to_retire(arm_stats: dict, prob_best: dict, min_impressions: int = 100) -> list:
    out = []
    for key, (a, b) in arm_stats.items():
        n = a + b
        if n >= min_impressions and prob_best[key] < 0.02:
            out.append(key)                      # 曝光够多且几乎不可能是最优
    return out
```

两个条件缺一不可。曝光不足的素材即使目前数据难看也不淘汰，它可能只是运气不好。另外，被归因环节确认的标题党素材直接淘汰。

每类人群至少保留两版素材。只剩一版时就失去了比较的基准。

## 改写

改写是这一章的核心。它和「Agent 评测与自进化平台」项目的 GEPA 一章是同一个结构：把表现和反馈交给模型，让它先诊断再改。

```text
你在为「{segment.name}」人群改进一条广告文案。

当前文案（点击率 {ctr}，区间 {lo}–{hi}）：
{parent.body}
它使用的卖点：{selling_points}　角度：{angle}　语气：{tone}

本轮归因结论（仅列出置信等级为高或中的）：
{findings}

这类人群的反馈原话：
点击的理由：{click_quotes}
没点的理由：{skip_quotes}

此前对这条文案尝试过但没有提升的改法：
{failed_attempts}

请完成：
1. 诊断：这条文案对这类人群还差在哪里？依据是上面的哪条结论或反馈？
2. 改写：给出一版新文案。只做一处实质性的改动。
3. 说明：改动的是卖点、角度、语气中的哪一项，改成了什么。

约束：只能使用可用卖点清单里的卖点：{available_points}。不超过 40 字。
不使用绝对化表述，不涉及清单之外的功效。
```

几处设计：

- **只列高和中置信的结论。** 低置信和无结论的不给改写模型看，避免它在没有依据的方向上发挥。
- **只做一处实质性改动。** 一次改了卖点又改了语气，下一轮即使变好也不知道是哪一项的功劳。这和「Agent 评测与自进化平台」项目里“修改要最小化”是同一个道理。
- **输出改了哪一项。** 新素材的标签据此更新，保证归因继续有效。
- **带上失败过的改法。** 避免在同一个方向上重复试错。

改写得到的新素材记录 `parent_id`，然后从审核的第一层重新走。

## 补缺

归因里的“未回应”结论指出了一个现有素材都没有覆盖的顾虑。这时改写已有素材不合适，应当写全新的素材。

处理分两种情况：

| 情况 | 做法 |
|---|---|
| 卖点清单里有能回应这个顾虑的卖点 | 用它为该人群生成新素材，走素材生成环节的正常流程 |
| 卖点清单里没有 | 不能编。在报告里向人提出：用户关心“会不会假白”，商品资料里没有相关信息，是否补充 |

第二种情况是系统该停下来问人的时刻。模型很乐意写一句“自然不假白”，而商品到底假不假白，它并不知道。

## 素材谱系

几轮之后，素材库里形成了一棵树：

```text
#101 场景｜亲切　“通勤路上十分钟，也别让脸白晒”          第1轮  3.1%
 └─#131 成分｜亲切　“不含酒精，敏感肌通勤也敢天天涂”      第2轮  7.4%
     ├─#152 成分｜理性　“0酒精配方，翻到成分表就能确认” 第3轮  9.6%
     └─#153 成分｜亲切　“不含酒精、推开就成膜，上班路上够用” 第3轮  8.8%
```

数字为示意。

这棵树有三个用处：

- 看板上可以展示一版好素材是怎样一步步改出来的，这是演示时最直观的画面。
- 回答“为什么最后是这一版”时有据可查：每一步改了什么、依据哪条归因结论。
- 发现走偏时可以回到某个祖先重新分叉。

## 防止越改越偏

自动优化有几种典型的走偏方式，要逐一设防：

| 走偏方式 | 表现 | 防护 |
|---|---|---|
| 趋同 | 各人群的素材越改越像，都收敛到同一种写法 | 每类人群保留至少两种不同的角度；新素材与已有素材相似度过高时丢弃 |
| 贴着红线 | 表述越来越接近违规边缘，因为夸张的说法点击率高 | 审核每轮必过；统计每轮被拦截的比例，持续上升时暂停并报告 |
| 标题党化 | 点击率持续上涨，下单率不涨甚至下降 | 以下单为优化目标；标题党检测 |
| 迎合模拟环境 | 素材在利用模拟环境的某个特点，而不是变得更好 | 人工每轮抽看头部素材；保留一组从不参与优化的模拟用户做验收 |

第二条值得展开。优化过程是没有道德感的，点击率是它唯一的方向。“一抹见效”比“使用后感觉清爽”吸引人，如果没有审核挡着，系统会稳定地朝夸大的方向演化。所以审核不能只在第一轮做一次，每一版改写都必须重新过。这也是为什么架构图里有那条从进化指回审核的线。

第四条对应「Agent 评测与自进化平台」项目的验收集思想。构造模拟用户池时留出一部分用户，试投和归因从不使用他们。全部轮次结束后，把最终素材和第一轮的素材一起投给这批留出用户比较一次。优化用的用户上涨了而留出用户上没涨，说明几轮下来只是拟合了那一批用户的噪声。

## 主管怎样决定继续还是停

每轮结束后，主管读归因报告和分配器的状态，按规则做决定：

| 情况 | 决定 |
|---|---|
| 各人群的第一名连续两轮稳定，且是最优的概率超过阈值 | 停止，输出报告 |
| 预算用完或达到最大轮数 | 停止，报告里说明哪些人群尚未收敛 |
| 某类人群所有素材持续无效 | 向人提议：放弃这类人群，或回到人群分层重新定义 |
| 审核拦截比例连续上升 | 暂停，等待人工查看 |
| 其他 | 继续下一轮 |

这张表写在主管的提示词里，同时预算上限和最大轮数由代码强制，主管无法越过。

```text
活动报告：清透防晒乳 SPF50+ 拉新（模拟环境 sim-v3）

共 4 轮，使用预算 8200 / 10000
生成素材 41 版，审核拦截 9 版，淘汰 22 版，最终保留 10 版

各人群最终推荐
  敏感肌    #152  成分｜理性    留出用户上相对首轮最优素材 +38%（区间 +12% 至 +61%）
  通勤白领  #147  场景｜亲切    +21%（区间 -3% 至 +44%，未达到显著）
  户外运动  #139  功效｜理性    +29%
  学生党    未收敛，所有素材接近基准，建议重新定义人群

主要发现
  1. 对敏感肌人群，成分信息比使用场景有效（高置信）
  2. 31 条反馈提到担心假白，商品资料中无相关信息，建议补充
  3. 第 3 轮起出现 2 版标题党素材，已淘汰

以上数据来自模拟试投环境，用于比较素材的相对表现，不代表真实投放效果。
```

数字为格式示意。注意通勤白领那一行：区间跨过了零，报告如实写“未达到显著”，而不是只报一个正的数字。

## 写进简历的写法

能写的：

- 设计并实现了营销素材从生产、审核、试投到优化的多 Agent 闭环，试投基于公开行为数据构建的模拟环境。
- 审核环节在自建评测集上的漏放率和误拦率。
- 在相同预算下，某种分配策略相比平均分配减少的累计损失。
- 多轮优化后，在留出的模拟用户上相对首轮素材的提升及区间。

不能写的：任何暗示真实投放效果的数字，例如“点击率提升了多少”而不注明模拟；以及把它写成某家公司的业务项目。

## 自己动手时的检查点

1. 跑通至少三轮完整的闭环，画出一棵素材谱系树。
2. 对比“一次改一处”和“不限制改动”两种设置下，归因结论的清晰程度。
3. 临时关掉对改写素材的审核，观察几轮之后素材的表述有没有向夸大的方向移动。然后把审核打开。
4. 在留出的模拟用户上比较首轮和末轮素材，报告提升和区间。

## 面试常见追问

- **闭环是怎么自优化的？** 淘汰、改写、补缺三个动作，以及改写时读什么、受什么约束。
- **自动优化会不会越改越离谱？** 四种走偏方式和对应的防护，重点讲审核每轮必过。
- **怎么知道优化是真的有效？** 留出用户上的对比、区间、未显著时如实报告，并说明模拟的边界。
- **什么时候需要人介入？** 卖点清单没有覆盖的顾虑、审核拦截持续上升、某类人群始终无效。
