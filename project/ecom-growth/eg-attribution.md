一轮试投结束，手里是一批曝光、点击、下单的日志。这一环节把日志变成结论：哪些卖点、哪种写法、对哪类人群有效，以及这些结论有多可信。归因的质量决定了下一轮改写的方向对不对。

## 归因要回答三层问题

| 层 | 问题 | 例子 |
|---|---|---|
| 素材 | 哪几版素材表现好 | 第 7 版在敏感肌人群上点击率最高 |
| 属性 | 好在哪个属性上 | 对敏感肌人群，成分角度普遍好于场景角度 |
| 原因 | 用户为什么有这种反应 | 多名用户的反馈提到“看到不含酒精才点进来” |

只做第一层，下一轮只能复制第 7 版。做到第二、三层，才知道该往哪个方向写新素材。素材生成一章要求每版素材带卖点、角度、语气的标签，就是为第二层准备的。

## 第一层：素材表现

按“素材乘人群”汇总，并给出区间而不只是一个点：

```python
def summarize(impressions: pd.DataFrame) -> pd.DataFrame:
    g = impressions.groupby(["creative_id", "segment_id"])
    s = g.agg(n=("clicked", "size"), clicks=("clicked", "sum"), orders=("ordered", "sum"))
    s["ctr"] = s.clicks / s.n
    # 用 Beta 分布的分位数给出 90% 区间，样本少时区间自然很宽
    s["ctr_lo"] = beta.ppf(0.05, 1 + s.clicks, 1 + s.n - s.clicks)
    s["ctr_hi"] = beta.ppf(0.95, 1 + s.clicks, 1 + s.n - s.clicks)
    return s
```

汤普森采样会让表现差的素材曝光很少，它们的区间很宽。报告里必须显示区间，否则一版只曝光了 30 次、点了 3 次的素材会以 10% 的点击率排到第一。

两个区间重叠的素材，不能说谁比谁好。

## 第二层：属性归因

把素材的标签展开，看每个属性取不同值时的表现：

```python
def attribute_effect(impressions, creatives, attr: str, segment_id: int) -> pd.DataFrame:
    df = impressions[impressions.segment_id == segment_id].merge(creatives, on="creative_id")
    return df.groupby(attr).agg(n=("clicked", "size"), ctr=("clicked", "mean"),
                                creatives=("creative_id", "nunique"))
```

得到这样一张表（数字为示意）：

| 人群：敏感肌 | 曝光 | 点击率 | 涉及素材数 |
|---|---|---|---|
| 角度：成分 | 420 | 9.8% | 3 |
| 角度：痛点 | 380 | 7.1% | 3 |
| 角度：场景 | 210 | 3.3% | 2 |

### 属性归因的三个坑

**混在一起的属性。** 成分角度的三版素材恰好都用了“不含酒精”这个卖点，那么点击率高是因为角度还是因为卖点，分不出来。生成方案矩阵时如果让各属性尽量交叉搭配，这里就容易分开。归因时检查一下：两个属性的取值高度绑定时，在报告里注明无法区分。

**素材数太少。** 表里“涉及素材数”一列很重要。某个角度只有一版素材，它的表现可能来自这一版的某句话，而不是角度本身。属性层面的结论至少要有两三版素材支持。

**分人群看和合起来看结论相反。** 合并所有人群时场景角度看上去最好，分人群看每一类人群里它都不是最好的。原因是场景角度的素材恰好更多地投给了本来点击率就高的人群。归因一律分人群做，不看合并后的总数。

第三个坑在真实的投放分析里非常常见，面试时能举出这个例子很加分。

## 第三层：读反馈

模拟环境为每次曝光都留了一句反馈。这是真实投放里没有的信息（真实用户不会告诉你为什么不点），在模拟里可以利用，但要记住它来自模型。

反馈量很大，分批归纳：

```text
下面是 {segment} 人群对若干版素材的第一反应，每条标注了是否点击。

请归纳：
1. 促使点击的理由有哪几类？每类给出出现次数和两条原话。
2. 导致不点的理由有哪几类？每类给出出现次数和两条原话。
3. 有没有哪种理由是当前素材普遍没有回应的？

只根据给出的反馈归纳，不要补充你自己的推测。
```

第三问最有价值。它可能揭示出人群定义里没有的顾虑，例如很多人提到“不知道会不会假白”，而卖点清单和人群设定里都没有这一项。这类发现来自模拟环境一章设置的隐藏属性，这也是试投能学到新东西的原因。

## 归因结论的结构

归因的输出是给进化环节用的，结构要固定：

```python
@dataclass
class Finding:
    segment_id: int
    kind: str            # works | fails | unaddressed | inconclusive
    statement: str       # 如“成分角度优于场景角度”
    support: dict        # 曝光量、涉及素材数、区间
    confidence: str      # high | medium | low
    quotes: list[str]    # 支持的反馈原话
```

`confidence` 的判定用明确的规则，不交给模型自由判断：

| 等级 | 条件 |
|---|---|
| high | 区间不重叠，至少三版素材支持，并且和反馈归纳的结论一致 |
| medium | 区间不重叠，但只有两版素材支持，或没有反馈佐证 |
| low | 区间重叠，或只有一版素材 |

规则里的数量门槛是本项目的设定。

`inconclusive` 是一类正式的结论：“这一轮的数据不足以判断语气的影响”。把它明确写出来，可以防止进化环节在没有依据的方向上乱改。

## 标题党检测

预算分配一章设了一个护栏：点击率高而下单率低的素材要标记。归因环节负责分析它：

```python
def clickbait(summary: pd.DataFrame, seg_cvr: float) -> pd.DataFrame:
    s = summary[summary.clicks >= 20].copy()
    s["cvr_after_click"] = s.orders / s.clicks
    return s[(s.ctr > s.ctr.median() * 1.3) & (s.cvr_after_click < seg_cvr * 0.6)]
```

被标记的素材连同它的正文和反馈交给模型看一眼：是不是文案的承诺和商品实际不符。确认之后，这版素材在进化环节被淘汰，对应的写法作为反例记录下来。

## 归因报告

每轮产出一份给人看的报告，结构固定：

```text
第 2 轮归因（模拟环境 sim-v3）

敏感肌人群
  有效   成分角度优于场景角度（高）  9.8% 对 3.3%，区间不重叠，5 版素材
  有效   “不含酒精”是被提到最多的点击理由（中）
  未回应 31 条反馈提到担心“假白”，当前素材均未涉及
  无结论 语气的影响：区间重叠

学生党人群
  无效   所有素材点击率均接近基准（高）  建议重新审视这类人群的定义

标题党：素材 #214（点击率高出中位数 60%，点击后下单率不足人群均值的一半）
```

报告头部照例标注数据来自模拟环境。

“学生党人群所有素材均无效”这类结论会被主管读到，由它决定是否回到人群分层环节。

## 自己动手时的检查点

1. 实现带区间的素材汇总，找出点击率排名靠前但区间很宽的素材。
2. 做属性归因，检查有没有两个属性绑定在一起分不开的情况。
3. 人为制造一次“分开看和合起来看结论相反”的数据，确认你的报告没有被合并数据误导。
4. 归纳反馈，看能否发现模拟环境里的隐藏属性。

## 面试常见追问

- **怎么知道是哪个因素带来的效果？** 素材带标签，分人群做属性归因，并讲三个坑。
- **样本少的时候结论可靠吗？** 给区间而不是点估计；区间重叠不下结论；明确写“无结论”。
- **点击率高就是好素材吗？** 讲标题党检测和点击后转化。
- **怎么证明报告可信？** 每条结论带支持的数据量、涉及素材数、置信等级和原话；等级由明确规则判定。
