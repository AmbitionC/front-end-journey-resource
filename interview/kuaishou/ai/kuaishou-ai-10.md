<details data-knowledge-key="css-script-boundaries">
<summary>（1）CSS 里面能写脚本吗？</summary>
</details>

<p>浏览器把 CSS 作为声明式样式语言解析，不把 JavaScript 语句当 CSS 规则执行。选择器、伪类和动画能表达一部分随状态变化的样式；请求接口、计算业务状态或任意事件处理通常交给 JavaScript。预处理器或脚本生成 CSS，也不等于 CSS 本身运行了脚本。</p>
<p>教学例子：鼠标悬停时改变颜色可用 CSS；点击按钮后查询业务数据，再决定显示什么内容，需要相应的脚本和应用逻辑。这个例子没有恢复原帖未给条件的“拖动轴”。</p>

知识导航：[CSS 与脚本执行的边界](../../../knowledge/html-css/css/css-script-boundaries.md)。

<details data-knowledge-key="api-idempotency">
<summary>（2）Java 接口向数据库新增数据时，怎样做到幂等？</summary>
</details>

<p>先定义一次逻辑操作的稳定标识，在明确作用域内由数据库唯一约束或原子账本争取唯一执行权，并在同库事务中一起提交业务数据与处理结果。相同请求重试复用已有结果，不同内容复用同一键应冲突；先查询再无约束插入会有竞态，换成 Java 语言也不会自动消除。</p>
<p>教学例子：同一创建请求因响应丢失而重发，两次携带同一操作键；只有一个事务创建记录，另一个返回已保存结果。具体业务表结构原文未给，这里不假定存在某个字段。</p>
